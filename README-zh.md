## 特点

- **更快:** 它在您的本地设备上运行，无需上传到服务器。
- **隐私和安全:** 您的数据永远不会离开您的设备。
- **节省时间:** 它可以批量处理多个视频。
- **经济实惠:** 个人使用免费。
- **编辑功能:** 批量创建视频剪辑，将多个视频合并为单个动作视频，按间隔截取屏幕截图，将常见视频格式转换为 720p mp4。

## 使用方法

- 安装 NodeJS 运行时，参考 [NodeJS](https://nodejs.org/en/download/prebuilt-installer)。
- 安装 ffmpeg（完整版），参考 [ffmpeg](https://www.ffmpeg.org/download.html)。
- 安装 git，参考 [git](https://git-scm.com/downloads)。
- 如果您有任何问题，请在互联网上搜索适用于您特定操作系统的教程。

注意：复制以下命令，在终端（Windows 上的 CMD 或 Powershell）中粘贴并运行。

1. 在终端中克隆此项目，命令如下：
   `git clone https://github.com/streamwhite/batch-video-edit.git`
2. 克隆后进入项目文件夹，命令如下：
   `cd batch-video-edit`
3. 安装依赖项（yarn 或 pnpm 也可以），命令如下：
   `npm install`
4. 构建项目，命令如下：
   `npm run build`
5. 启动项目（首次设置后只需从此步骤开始运行应用程序），命令如下：
   `npm run start`
6. 在浏览器中打开 http://localhost:3000/，加载需要几秒钟。
7. 开始剪辑视频。
